# Studio Dumbar tool

This project lives in the Studio Dumbar GitHub and shows up in the SD Tool Warehouse.

- Save, version and copy it with the **sd-save** skill. Don't create branches or pull requests; everything goes to `main`.
- Keep `sd-tool.json` (name, description, type, client, tags, author) up to date when the tool changes.
- Never put keys or passwords in the code. Use `sd secret`.
- `.github/workflows/deploy.yml` puts the tool live on every save. Leave it as is.
